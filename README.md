# Jacqueline's Korean Lessons

Self-contained interactive HTML lessons (math, reading, writing, beginner Korean) themed around Korean food & culture.

## Day 1
Open `index.html` or use GitHub Pages once enabled.

Korean listen-and-say: every vocab word in `lessons/day1/korean.html` has model MP3s in `audio/korean/` plus record-and-compare (same pattern as Ace's Cantonese lessons). Voice: `ko-KR-SunHiNeural`.
